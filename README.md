# 🏦 Banking Web Application

A secure Banking Web Application developed using **Spring Boot**, **Spring Security**, **Thymeleaf**, **MySQL**, **HTML**, **CSS**, and **Java**.

---

## 📌 Overview

This project provides a secure online banking platform where users can register, log in, manage their accounts, transfer money, apply for loans, and view transaction history.

The application follows the MVC architecture and uses Spring Security for authentication and authorization.

---

## 🚀 Features

- User Registration
- Secure Login & Authentication
- Spring Security
- Deposit Money
- Withdraw Money
- Money Transfer
- Transaction History
- Loan Application
- OTP Verification
- Forgot Password
- User Profile
- Admin Dashboard
- Role-Based Access Control

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/Mowneka/BankingWebApplication.git
```

Go inside the project

```bash
cd BankingWebApplication
```

Configure MySQL in

```
application.properties
```

Run

```bash
mvn spring-boot:run
```

Open

```
http://localhost:8080
```
